<div className="tsh-caps">Fixtures</div>

→ Every workflow that ships with the repository, each with a step map and the JSON file itself. Copy the closest one into `workflows/users/` and change it from there.

The **examples** are the flows the e2e suites run against: each isolates one mechanism, from the plain step shape to conditional fields, document upload, phone verification and scoring, and is written as `custom` steps. The **built-in** workflow is a production-grade flow the engine ships with, one page per revision: revision 1 as `custom` steps and revision 2 as specialized ones, each naming the other. Filter by the connector capability a workflow uses.
