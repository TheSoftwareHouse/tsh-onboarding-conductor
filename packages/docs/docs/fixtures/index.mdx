→ Every workflow that ships with the repository, each with a step map and the JSON file itself. Copy the closest one into `workflows/users/` and change it from there.

The **examples** back local development and CI: each isolates one mechanism, from the plain step shape to conditional fields, document upload, provider callbacks and scoring. The **built-in** workflows are production-grade flows the engine ships with, in both authored forms. Filter by the connector capability a workflow uses.
